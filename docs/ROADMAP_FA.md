# نقشه راه تاریخ‌یار

این فایل پیشنهادهای توسعه نسخه‌های بعدی پس از 1.6.0 را اولویت‌بندی می‌کند.

## نسخه 1.7 — تجربه روزانه
- ویجت صفحه اصلی برای تاریخ شمسی امروز، مناسبت و شمارش تا تولد
- انتخاب چند پروفایل تولد برای اعضای خانواده و دوستان
- یادآوری تولد و رویدادهای سنی با زمان قابل تنظیم
- Favorites برای ابزارهای پرکاربرد
- انتخاب بین تم روشن، تیره و خودکار
- تنظیم اندازه فونت و حالت دسترس‌پذیری

## نسخه 1.8 — تقویم و مناسبت‌ها
- تقویم ماهانه شمسی کامل
- مناسبت‌های رسمی ایران
- مناسبت‌های شخصی قابل ساخت توسط کاربر
- نمایش تعطیلات رسمی
- جست‌وجوی تاریخ و مناسبت
- تبدیل سریع تاریخ با انتخاب از Date Picker شمسی

## نسخه 1.9 — ابزارهای حرفه‌ای
- محاسبه روز کاری بین دو تاریخ
- افزودن/کم‌کردن تعداد روز، هفته، ماه و سال از یک تاریخ
- محاسبه سن در یک تاریخ دلخواه، نه فقط امروز
- مقایسه سن دو نفر
- محاسبه فاصله تا یک رویداد آینده با Countdown زنده
- خروجی کارت تصویری از نتیجه سن یا تولد برای Share

## نسخه 2.0 — شخصی‌سازی و پشتیبان‌گیری
- پروفایل محلی کاربر
- Backup/Restore داده‌ها به فایل رمزگذاری‌شده
- همگام‌سازی اختیاری بین دستگاه‌ها در صورت اضافه شدن حساب کاربری
- تنظیمات کامل Notification برای هر نوع رویداد
- قالب‌های گرافیکی مختلف برای کارت نتیجه
- امکان انتخاب مجموعه آیکن و رنگ برنامه

## ایده‌های درآمدزایی اختیاری
- نسخه رایگان بدون محدودیت در محاسبات اصلی
- قالب‌های Premium برای کارت‌های خروجی و ویجت‌ها
- بسته آیکن/تم حرفه‌ای
- حذف تبلیغ در صورت اضافه شدن تبلیغات در آینده
- اشتراک اختیاری برای Backup ابری و Sync؛ قابلیت‌های آفلاین پایه نباید پشت اشتراک قفل شوند

## کیفیت و نگهداری
- افزایش Unit Testهای تقویم برای بازه‌های سالی مختلف و سال کبیسه
- UI Test برای Drawer و Back Stack
- تست نصب Update روی نسخه قبلی با همان Signing Certificate
- Screenshot Test برای صفحات اصلی
- بررسی Accessibility و TalkBack
- Crash reporting اختیاری با رعایت حریم خصوصی در صورت آنلاین شدن پروژه
