# نقشه راه پس از تاریخ‌یار 2.0

قابلیت‌های برنامه‌ریزی‌شده برای 1.7 تا 2.0 در نسخه 2.0 یکپارچه شده‌اند: ویجت، چند پروفایل، Reminder، Favorites، Dark Mode، تقویم ماهانه، مناسبت شخصی، جست‌وجو، Date Picker، ابزارهای حرفه‌ای، کارت تصویری، Backup رمزگذاری‌شده و شخصی‌سازی.

## نسخه 2.1 — تقویم حرفه‌ای‌تر
- بسته آفلاین مناسبت‌های قمری برای هر سال با امکان بروزرسانی فایل داده
- Import/Export با استاندارد ICS برای انتقال رویدادها به تقویم گوشی
- نمایش شماره هفته، فصل و روز کاری باقی‌مانده ماه
- فیلتر تقویم بر اساس خانواده، کار، سالگرد و مناسبت رسمی
- چند مدل ویجت با اندازه‌های 1x1، 2x2 و 4x2

## نسخه 2.2 — یادآوری هوشمند
- یادآوری چندمرحله‌ای؛ یک هفته، سه روز و یک روز قبل از رویداد
- Snooze و «یادآوری دوباره» از خود Notification
- قالب آماده برای تولد، سالگرد ازدواج، قسط، چک و تمدید مدارک
- نمایش نزدیک‌ترین رویدادها در صفحه Home
- تنظیم صدای اعلان و حالت سکوت برای هر دسته

## نسخه 2.3 — امنیت و داده
- قفل برنامه با PIN و Biometric
- رمزگذاری انتخابی داده‌های محلی حساس
- نسخه‌بندی Backup و Migration خودکار بین نسخه‌های قدیمی و جدید
- خروجی CSV/JSON برای پروفایل‌ها و رویدادها
- بررسی سلامت Backup قبل از جایگزینی داده فعلی

## نسخه 2.4 — اشتراک و خروجی گرافیکی
- ویرایشگر کارت تولد با انتخاب پس‌زمینه، فونت، چینش و استیکر
- قالب‌های مناسب استوری Instagram و وضعیت WhatsApp/Telegram
- QR برای اشتراک رویداد یا تاریخ بدون ارسال اطلاعات اضافه
- خروجی PDF سالانه از تولدها و مناسبت‌های ذخیره‌شده

## نسخه 2.5 — تجربه سریع‌تر
- جست‌وجوی سراسری از Home
- فرمان صوتی محلی برای عباراتی مانند «سن متولد ۱۳۷۵ را حساب کن» در صورت پشتیبانی دستگاه
- میانبرهای Android App Shortcut برای محاسبه سن، تقویم و رویداد جدید
- دسترس‌پذیری بهتر برای TalkBack و کنتراست بالا

## نسخه 3.0 — Sync آنلاین اختیاری
- حساب کاربری کاملاً اختیاری
- Sync رمزگذاری‌شده بین چند دستگاه
- Conflict Resolution برای تغییرات همزمان
- بازیابی نسخه‌های قدیمی Backup
- نسخه وب یا پنل سبک فقط برای مدیریت داده‌های Sync شده

## کیفیت فنی دائمی
- Unit Test بیشتر برای تبدیل تاریخ و سال کبیسه
- UI Test برای Drawer، Back، Date Picker و CRUD
- تست واقعی Upgrade از APK قبلی با Signing Certificate ثابت
- Screenshot Test برای تم روشن/تیره
- بررسی مصرف باتری Alarmها و ویجت
