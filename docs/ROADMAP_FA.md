# نقشه راه تاریخ‌یار

## V1.0.0 — پایه آفلاین

- محاسبه سن
- اختلاف تاریخ
- تبدیل شمسی/میلادی
- محاسبه تاریخ جلو/عقب
- تاریخ امروز
- RTL و Dark Mode
- موتور تقویم مستقل

## V1.1 — بهبود تجربه کاربری

- انتخابگر تاریخ گرافیکی بهتر
- انیمیشن‌های نتیجه
- اشتراک‌گذاری نتیجه
- صفحه تنظیمات کامل‌تر
- بهبود دسترس‌پذیری

## V1.2 — مناسبت‌ها

- ذخیره تولد و مناسبت
- دسته‌بندی افراد
- شمارش معکوس رویداد
- اعلان محلی

## V1.3 — ویجت

- ویجت تاریخ امروز
- ویجت تولد بعدی
- تنظیم ظاهر ویجت

## V2 — مدل درآمدی

در صورت تصمیم تجاری:

- تبلیغات برای نسخه رایگان
- Pro Unlock به‌صورت خرید یک‌باره
- Provider مستقل برای Cafe Bazaar Poolakey
- Provider مستقل برای Google Play Billing

منطق Premium باید از Featureها و Core تاریخ جدا باقی بماند تا هیچ وابستگی فروشگاهی وارد موتور برنامه نشود.

## V3 — قابلیت‌های آنلاین اختیاری

فقط در صورت نیاز محصول:

- حساب کاربری
- Sync ابری
- Backup مناسبت‌ها
- انتقال اطلاعات بین دستگاه‌ها

این موارد نباید برای قابلیت‌های اصلی آفلاین اجباری شوند.
