# راهنمای انتشار تاریخ‌یار

## کافه‌بازار

برای انتشار معمولی برنامه نیازی به API اختصاصی بازار در داخل برنامه نیست. فایل Release امضاشده در پنل توسعه‌دهندگان بارگذاری می‌شود.

در V1 پرداخت درون‌برنامه‌ای وجود ندارد، بنابراین Poolakey یا SDK پرداخت دیگری اضافه نمی‌شود.

اگر در نسخه‌های آینده Pro Unlock اضافه شود، Billing بازار باید به‌عنوان Provider جداگانه اضافه شود و منطق Premium از Core برنامه مستقل بماند.

## Google Play

برای انتشار معمولی، فایل Android App Bundle (AAB) از طریق Play Console بارگذاری می‌شود. API انتشار فقط برای اتوماسیون CI/CD لازم است و برای خود اپلیکیشن ضروری نیست.

اگر فروش قابلیت دیجیتال در نسخه Google Play اضافه شود، Billing آن نسخه باید مطابق الزامات جاری Google Play پیاده‌سازی شود.

## اصل مشترک

شناسه برنامه و مسیر Signing باید قبل از اولین انتشار رسمی قطعی شوند. افزودن Billing یا Ads در آینده نیازی به تغییر applicationId ندارد.
