# معماری تاریخ‌یار

## هدف نسخه ۱

نسخه اول عمداً کوچک ولی کامل طراحی شده است. هسته محاسبات هیچ وابستگی به UI، شبکه یا دیتابیس ندارد تا توسعه قابلیت‌های بعدی باعث بازنویسی منطق تاریخ نشود.

## پوشه‌ها

- `core/date`: مدل تاریخ شمسی، تبدیل شمسی/میلادی، کبیسه، اختلاف و محاسبات تاریخ.
- `core/format`: تبدیل اعداد به فارسی و قالب‌بندی خروجی‌ها.
- `core/ui/theme`: رنگ، تایپوگرافی و تم روشن/تیره.
- `ui/components`: کامپوننت‌های مشترک ورودی تاریخ، دکمه، کارت نتیجه و انتخاب‌گرها.
- `feature/home`: صفحه خانه و میانبرها.
- `feature/age`: محاسبه سن.
- `feature/difference`: اختلاف دو تاریخ.
- `feature/tools`: تبدیل تاریخ و محاسبه تاریخ آینده/گذشته.

## مسیر توسعه پیشنهادی

### v1.1
- ذخیره تاریخ‌های مهم با Room
- نام‌گذاری مناسبت‌ها
- اشتراک‌گذاری نتیجه به شکل متن/کارت
- کپی سریع تاریخ تبدیل‌شده

### v1.2
- اعلان تولد و مناسبت
- Home Screen Widget
- تنظیمات نمایش اعداد فارسی/لاتین
- انتخاب تم دستی

### v1.5
- تقویم ماهانه کامل شمسی
- تعطیلات رسمی
- محاسبه روزهای کاری
- تبدیل قمری با تعریف واضح نوع تقویم قمری

### v2.0 تجاری
- لایه Monetization جدا از هسته
- تبلیغات ویدیویی Rewarded در قابلیت‌های مشخص
- خرید نسخه Pro / حذف تبلیغات
- اتصال به پرداخت کافه‌بازار بدون وابسته کردن موتور تاریخ به SDK پرداخت

## اصل مهم

SDK تبلیغات یا پرداخت نباید داخل `core/date` یا featureهای محاسباتی قرار گیرد. این SDKها در لایه مستقل `monetization` اضافه می‌شوند و فقط وضعیت دسترسی کاربر را در اختیار UI می‌گذارند.
