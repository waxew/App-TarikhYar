# تاریخ‌یار — TarikhYar 2.0

تاریخ‌یار یک برنامه فارسی Android برای محاسبه سن، تبدیل و مقایسه تاریخ، اطلاعات تولد، تقویم شمسی و مدیریت رویدادهای شخصی است. محاسبات اصلی آفلاین انجام می‌شوند و اینترنت فقط برای بررسی اختیاری نسخه جدید استفاده می‌شود.

## Figma Product Master
مرجع یکپارچه طراحی، Screenها، Design System، Flowها و معماری پروژه در Figma:

https://www.figma.com/design/k6zg11yiKZ3m3Yy4LtuG7S

نگاشت Nodeهای Figma به فایل‌های Kotlin/Jetpack Compose در `docs/FIGMA_HANDOFF.md` نگهداری می‌شود.

## نسخه فعلی
- Version Name: `2.0.0`
- Version Code: `20`
- Application ID: `ir.tarikhyar.app`
- minSdk: 26 (Android 8.0)
- targetSdk / compileSdk: 36
- Kotlin + Jetpack Compose

## امکانات نسخه 2.0
- محاسبه دقیق سن و اطلاعات کامل تولد
- تبدیل شمسی، میلادی و قمری
- رویدادهای سنی و طالع چینی
- چند پروفایل برای خود کاربر، خانواده و دوستان
- علاقه‌مندی و یادآوری جداگانه برای پروفایل‌ها
- تقویم ماهانه شمسی با تعطیلات ثابت خورشیدی
- مناسبت‌های شخصی قابل ساخت، ویرایش، حذف و جست‌وجو
- Date Picker شمسی بدون نیاز به تایپ
- محاسبه روز کاری بین دو تاریخ
- جمع و تفریق روز، هفته، ماه و سال از تاریخ
- محاسبه سن در یک تاریخ دلخواه
- مقایسه سن دو نفر
- Countdown زنده تا رویداد آینده
- خروجی کارت PNG از نتیجه سن یا تولد برای Share
- ویجت صفحه اصلی با تاریخ امروز و نزدیک‌ترین تولد
- تم روشن، تیره و خودکار
- سه رنگ اصلی، دو سبک آیکن و سه قالب کارت اشتراک
- اندازه متن کوچک، معمولی و درشت
- تنظیمات مستقل برای اعلان تولد، رویداد، رویداد سنی و بروزرسانی
- پشتیبان/بازیابی رمزگذاری‌شده AES-GCM
- همگام‌سازی اختیاری بین دستگاه‌ها با انتقال فایل پشتیبان رمزگذاری‌شده
- منوی همبرگری جدید با پروفایل و تصویر کاربر
- Back Stack واقعی؛ دکمه Back به صفحه قبلی برمی‌گردد
- بررسی نسخه جدید از `version.json`

## حریم خصوصی
داده‌های پروفایل‌ها، مناسبت‌ها، تنظیمات و Backup روی دستگاه کاربر نگهداری می‌شوند. تاریخ‌یار برای این امکانات حساب کاربری یا سرور اجباری ندارد.

## Signing و انتشار
کلید خصوصی Release در مخزن عمومی نگهداری نمی‌شود. تمام APK/AABهای بعدی باید با Certificate ثابت تاریخ‌یار امضا شوند تا Update روی نسخه قبلی نصب شود. اطلاعات عمومی Certificate در `info.txt` ثبت شده است.

## ساخت
پروژه با JDK 17، Gradle 8.13، AGP 8.13.2 و Kotlin 2.2.21 ساخته می‌شود. Workflow عمومی GitHub تست‌ها و Release بدون امضا را Build می‌کند؛ Signing نهایی باید در محیط خصوصی انجام شود.
