# تاریخ‌یار (TarikhYar)

تاریخ‌یار یک اپلیکیشن اندروید فارسی برای محاسبه سن، تبدیل و اختلاف تاریخ، اطلاعات تولد، رویدادهای سنی و ابزارهای مرتبط با تاریخ است. هسته محاسبات اصلی به‌صورت محلی اجرا می‌شود و اینترنت فقط برای بررسی نسخه جدید استفاده می‌شود.

## نسخه فعلی: 1.6.0

### تغییرات نسخه 1.6
- اضافه شدن منوی همبرگری راست‌چین در صفحه اصلی
- گزینه‌های تنظیمات، معرفی به دوستان، درباره ما، تماس با ما و درباره نرم افزار در Drawer
- اضافه شدن صفحات مستقل «درباره ما»، «تماس با ما» و «درباره نرم افزار»
- صفحه درباره نرم افزار فقط توضیح کوتاه برنامه و شماره نسخه را نمایش می‌دهد و اطلاعات فنی مانند package name در UI نمایش داده نمی‌شود
- اصلاح کامل Back Navigation با Back Stack داخلی؛ دکمه Back گوشی ابتدا به صفحه قبلی برمی‌گردد
- اگر Drawer باز باشد، Back ابتدا Drawer را می‌بندد
- جلوگیری از تکرار Notification بروزرسانی برای یک versionCode در هر اجرای برنامه
- اضافه شدن timeout به بررسی آنلاین بروزرسانی برای جلوگیری از انتظار طولانی در شبکه ضعیف
- جلوگیری از Crash صفحه تماس در دستگاهی که برنامه ایمیل ندارد
- Release Build صراحتاً `isDebuggable = false` است
- اعمال استاندارد کامنت‌گذاری آموزشی AS Team روی فایل‌های Kotlin/KTS پروژه
- بروزرسانی مستندات معماری، انتشار و Roadmap

### قابلیت‌های اصلی
- محاسبه سن دقیق شمسی به سال، ماه و روز
- نمایش زمان باقی‌مانده تا تولد بعدی
- تبدیل تاریخ شمسی و میلادی
- نمایش معادل تاریخ تولد در شمسی، میلادی و قمری
- محاسبه اختلاف دو تاریخ
- رویدادهای سنی مانند پیش‌دبستانی، کلاس اول، ۱۸ سالگی و موارد برنامه‌ریزی
- طالع‌بینی چینی و داده‌های فرهنگی/سرگرمی مرتبط با سال تولد
- مرکز اعلان‌ها و Notification آزمایشی
- بررسی آنلاین نسخه جدید از `version.json`
- رابط کاربری فارسی، RTL و مبتنی بر Jetpack Compose

> بخش‌های طالع‌بینی، ویژگی‌های شخصیتی، رنگ/گل/عدد شانس و سازگاری صرفاً محتوای سرگرمی و فرهنگی هستند و ادعای علمی ندارند.

## منوی همبرگری
ساختار فعلی Drawer:
1. تنظیمات
2. معرفی به دوستان
3. درباره ما
4. تماس با ما
5. درباره نرم افزار

Drawer در حالت RTL از سمت راست باز می‌شود.

## رفتار دکمه Back
ناوبری نسخه 1.6 از Back Stack استفاده می‌کند. ورود به هر صفحه، صفحه قبلی را در تاریخچه ثبت می‌کند. Back سخت‌افزاری و دکمه Back داخل AppBar از همان تاریخچه استفاده می‌کنند. در صفحه خانه و وقتی Drawer بسته است، Back سیستم می‌تواند برنامه را طبق رفتار استاندارد Android ببندد.

## استاندارد کامنت‌گذاری سورس
پروژه از قانون مستندسازی AS Team استفاده می‌کند. فایل `tools/apply_source_comments.py` برای فایل‌های Kotlin و Kotlin Script توضیح آموزشی قبل از خطوط کد اضافه می‌کند تا هدف هر بخش هنگام باز کردن سورس مشخص باشد. فایل‌های JSON که از نظر فرمت اجازه Comment ندارند در مستندات جانبی توضیح داده می‌شوند.

## Build و امضا
نسخه رسمی باید همیشه با همان کلید دائمی تاریخ‌یار امضا شود تا نسخه‌های جدید روی نسخه قبلی نصب شوند. **Keystore و رمز آن نباید داخل مخزن عمومی یا سورس ZIP قرار بگیرند.** فایل `info.txt` در بسته سورس تحویلی فقط Fingerprintهای گواهی، مشخصات فنی Build و راهنمای نگهداری امن کلید را ثبت می‌کند.

## تست انتشار
قبل از تحویل نسخه پابلیش این مراحل در CI اجرا می‌شوند:
- Unit Test
- `assembleRelease`
- امضای Release با کلید ثابت برنامه
- `apksigner verify`
- `zipalign` با هم‌ترازی 16KB
- نصب APK روی Android Emulator
- کنترل versionName و versionCode نصب‌شده
