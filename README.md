# تاریخ‌یار (TarikhYar)

اپلیکیشن اندروید فارسی و آفلاین برای محاسبه سن، تبدیل تاریخ و اطلاعات مرتبط با تولد.

## نسخه فعلی: 1.3.0

### تغییرات 1.3
- بازطراحی کامل هویت بصری با پالت قرمز، مرجانی و کرم و کارت‌های گردتر
- تایپوگرافی نرم‌تر و دوستانه‌تر
- لوگوی ساده‌شده: فقط تقویم ترنسپرنت، بدون نوشته، کیک، ماه یا پنل پشت
- سن دقیق شمسی و نمایش سال/ماه/روز
- تبدیل تاریخ تولد به میلادی و قمری و نمایش نام ماه‌ها
- حیوان سال ایرانی، ترکی و طالع چینی
- برج میلادی
- خصوصیات ماه تولد و داده‌های سرگرمی: رنگ، گل، بو، طعم، جواهر، حیوان، درخت، گیاه، ادویه، فلز، شعار، عدد شانس و سازگاری
- تعداد ماه، هفته، روز، ساعت، دقیقه و ثانیه سپری‌شده
- تعداد شمع تولد و زمان مانده تا تولد بعدی
- تاریخ کامل شدن 18 سالگی
- نقاط عطف پیش‌دبستانی 1، پیش‌دبستانی 2 و کلاس اول
- محاسبه سن هر رویداد از تاریخ شروع: ازدواج، عقد، پاکی، اشتغال، شرکت و حیوان خانگی
- سه‌رقم‌سه‌رقم جدا کردن اعداد در نتایج بزرگ

> داده‌های طالع‌بینی، خصوصیات ماه تولد، رنگ/گل/عدد شانس و سازگاری صرفاً محتوای سرگرمی و فرهنگی هستند و ادعای علمی ندارند.

## فناوری
- Kotlin
- Jetpack Compose
- minSdk 26 / targetSdk 36
- کاملاً آفلاین در نسخه 1.3
- بدون Billing و بدون Ads
