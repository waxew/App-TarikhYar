# تاریخ‌یار (TarikhYar)

اپلیکیشن اندروید فارسی برای محاسبه سن، تبدیل و اختلاف تاریخ، اطلاعات تولد، رویدادهای سنی و ابزارهای مرتبط با تاریخ.

## نسخه فعلی: 1.5.0

### رابط کاربری نسخه 1.5
- بازطراحی صفحه خانه با هویت قرمز، صورتی و کرم، کارت‌های سفید و گوشه‌های گرد
- کارت‌های گرافیکی برای محاسبه سن، اطلاعات تولد، اختلاف تاریخ، تبدیل تاریخ، رویدادهای سنی و طالع‌بینی چینی
- نوار بالای صفحات با دکمه‌های واقعی بازگشت و اشتراک‌گذاری
- صفحه محاسبه سن با نمایش بزرگ سن، آواتار، آمار سال/ماه/هفته/روز و شمارش تا تولد بعدی
- صفحه اطلاعات تولد با تب‌های شمسی، میلادی و قمری و کارت‌های معادل تاریخ
- صفحه طالع‌بینی چینی با حیوان سال، سال‌های هم‌چرخه، ویژگی‌ها و کارت‌های سرگرمی
- صفحه رویدادهای سنی با ردیف‌های گرافیکی و آیکن‌های رنگی

### قابلیت‌های اصلی
- سن دقیق شمسی به سال، ماه و روز
- تبدیل تاریخ تولد به میلادی و قمری و نمایش نام ماه‌ها
- نمایش روز هفته تولد
- حیوان سال ایرانی، ترکی و چینی
- برج میلادی
- اطلاعات سرگرمی مرتبط با ماه/سال تولد مانند رنگ، گل، عدد شانس، درخت، گیاه و موارد مشابه
- تعداد روز، هفته، ماه، ساعت و دقیقه سپری‌شده
- تعداد شمع تولد و زمان مانده تا تولد بعدی
- تاریخ کامل شدن 18 سالگی
- نقاط عطف پیش‌دبستانی 1، پیش‌دبستانی 2، کلاس اول و سن گواهینامه بر اساس سن
- محاسبه اختلاف دو تاریخ
- تبدیل و جابه‌جایی تاریخ
- جداکردن سه‌رقمی اعداد بزرگ

### تنظیمات، اعلان و بروزرسانی
- صفحه تنظیمات واقعی
- روشن/خاموش کردن اعلان‌های برنامه
- درخواست مجوز Notification در Android 13 به بالا
- ارسال اعلان آزمایشی
- صفحه مرکز اعلان‌ها
- بررسی آنلاین آخرین نسخه از `version.json`
- نمایش اعلان در صورت انتشار نسخه جدید، در صورت فعال بودن اعلان‌ها
- نمایش نسخه و Version Code در تنظیمات

> بخش‌های طالع‌بینی، ویژگی‌های شخصیتی، رنگ/گل/عدد شانس و سازگاری صرفاً محتوای سرگرمی و فرهنگی هستند و ادعای علمی ندارند.

## فناوری
- Kotlin
- Jetpack Compose
- minSdk 26
- targetSdk 36
- `applicationId`: `ir.tarikhyar.app`
- بدون Billing و بدون تبلیغات در نسخه 1.5
- هسته محاسبات تاریخ همچنان مستقل از رابط کاربری است

## Build و امضا
CI عمومی فقط تست و Build بدون امضا انجام می‌دهد. کلید Signing دائمی برنامه داخل مخزن قرار نمی‌گیرد. نسخه‌های رسمی باید با کلید ثابت تاریخ‌یار امضا شوند تا امکان Update روی نسخه‌های قبلی حفظ شود.

نسخه 1.5.0 قبل از تحویل با Unit Test، Build Release، بررسی امضا و نصب واقعی روی Android Emulator تست شده است.
