# تاریخ‌یار (TarikhYar)

تاریخ‌یار یک اپلیکیشن اندروید فارسی، آفلاین و سبک برای محاسبات روزمره تاریخ است. نسخه ۱ با هدف سادگی رابط کاربری، سرعت بالا و امکان توسعه بدون بازنویسی هسته ساخته شده است.

## وضعیت پروژه

- نسخه: `1.0.0`
- Version Code: `1`
- پلتفرم: Android
- زبان: Kotlin
- UI: Jetpack Compose
- معماری: Feature-based + Core مستقل
- جهت رابط: RTL / فارسی
- وضعیت شبکه در V1: کاملاً آفلاین
- پرداخت درون‌برنامه‌ای در V1: ندارد
- تبلیغات در V1: ندارد

## امکانات نسخه ۱

- نمایش تاریخ امروز شمسی و میلادی
- محاسبه سن دقیق بر حسب سال، ماه و روز
- نمایش تعداد روزها و هفته‌های زندگی
- محاسبه فاصله تا تولد بعدی
- نمایش روز هفته تولد
- محاسبه اختلاف دقیق بین دو تاریخ شمسی
- نمایش اختلاف به سال/ماه/روز، روز، هفته، ساعت و دقیقه
- تبدیل تاریخ شمسی و میلادی
- اضافه یا کم کردن روز، هفته، ماه و سال از یک تاریخ
- پشتیبانی از سال کبیسه و تاریخ‌های مرزی
- Light Mode و Dark Mode
- رابط کاربری فارسی و RTL

## ساختار سورس

```text
app/src/main/java/ir/tarikhyar/app/
├── core/
│   ├── date/          # موتور تقویم و محاسبات تاریخ
│   ├── format/        # قالب‌بندی اعداد و متن فارسی
│   └── ui/theme/      # رنگ‌ها و تم برنامه
├── feature/
│   ├── home/          # صفحه اصلی
│   ├── age/           # محاسبه سن
│   ├── difference/    # اختلاف دو تاریخ
│   └── tools/         # تبدیل و ابزارهای تاریخ
└── ui/components/     # کامپوننت‌های مشترک رابط
```

منطق تقویم از UI جدا نگه داشته شده است تا در نسخه‌های بعدی بتوان قابلیت‌هایی مانند ویجت، مناسبت‌ها، اعلان‌ها، تبلیغات و پرداخت را بدون تغییر اساسی در موتور تاریخ اضافه کرد.

## توسعه نسخه‌های بعدی

برنامه از ابتدا برای توسعه تدریجی طراحی شده است. موارد زیر برای نسخه‌های بعدی در نظر گرفته شده‌اند:

- ذخیره تولدها و مناسبت‌های مهم
- اعلان و یادآوری تولد و مناسبت
- ویجت صفحه اصلی اندروید
- اشتراک‌گذاری نتیجه محاسبات به‌صورت کارت تصویری
- تعطیلات رسمی و روزهای کاری
- تقویم قمری در صورت نیاز
- تبلیغات اختیاری برای نسخه رایگان
- نسخه Pro / پرداخت درون‌برنامه‌ای کافه‌بازار و Google Play
- پشتیبان‌گیری و همگام‌سازی ابری در صورت آنلاین شدن محصول

> در نسخه ۱ هیچ SDK پرداخت، تبلیغات یا سرویس آنلاین اضافه نشده است. تنها معماری پروژه طوری نگه داشته شده که این قابلیت‌ها بعداً به شکل مستقل اضافه شوند.

## نکته مهم درباره شناسه برنامه

`applicationId` پروژه باید از زمان اولین انتشار رسمی ثابت بماند. تغییر آن در آینده باعث می‌شود فروشگاه‌ها برنامه را به‌عنوان اپلیکیشن جدید تشخیص دهند و مسیر آپدیت کاربران قبلی قطع شود.

قبل از اولین انتشار رسمی در کافه‌بازار یا Google Play، شناسه نهایی برنامه و Signing Key باید قطعی و امن نگه‌داری شوند.

## اجرای پروژه

1. پروژه را در Android Studio باز کنید.
2. اجازه دهید Gradle Sync کامل شود.
3. Android SDK موردنیاز پروژه را نصب کنید.
4. یک دستگاه واقعی یا Emulator انتخاب کنید.
5. Run را اجرا کنید.

برای ساخت نسخه تست:

```bash
gradle assembleDebug
```

برای انتشار رسمی باید Release Build با کلید امضای دائمی پروژه ساخته شود.
